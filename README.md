# Java Calculator

Консольный калькулятор на Java для домашнего задания по модулю 2.

## Возможности

- Сложение, вычитание, умножение и деление чисел `double`
- Продолжение вычислений с предыдущим результатом
- `C` или `c` — сброс результата и новый ввод первого числа
- `S` или `s` — завершение программы
- Обработка деления на ноль, неподдерживаемых операторов и некорректного числового ввода

## Запуск

Требуется JDK 17 или новее.

```bash
javac Main.java
java Main
```

Также можно открыть `Main.java` в IntelliJ IDEA и запустить метод `main`.

## Пример

```text
Введите первое число: 2
Введите операцию (+, -, *, /), C или S: +
Введите второе число: 3
Результат: 5.0
Введите операцию (+, -, *, /), C или S: *
Введите второе число: 4
Результат: 20.0
```

Для десятичных дробей используйте точку: `2.5`.
